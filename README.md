# 🎮 Quiz Blitz Pro

**Interactive multiplayer quiz platform** with real-time collaboration, team library, and advanced analytics.

- 👥 **100+ concurrent players** in live sessions
- 🔄 **Real-time collaborative editing** with conflict resolution
- 🔒 **Host-only edits** during live sessions
- 📊 **Advanced analytics** with performance tracking
- ☁️ **Cloud-native** with MongoDB + Node.js + WebSocket
- 🔐 **Team-based access** with shared TEAM_KEY

## 🚀 Quick Start

### Prerequisites
- Node.js 16+
- MongoDB 4.4+
